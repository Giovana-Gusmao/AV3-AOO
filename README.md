AV3- Análise Orientada a Objetos <br>
Professor: Celso Barreto <br>
Centro Universitário Jorge Amado <br>

Esse trabalho desenvolvido tem como objetivo transformar um problema real dos profissionais de Psicologia em um modelo orientado a objetos consistente, verificável e suficientemente detalhado para orientar uma futura implementação, através de especificação, UML, persistência, qualidade e processos do ciclo de vida de software. 
Sendo a sua situação problema a de como modelar uma plataforma flexível e segura para profissionais de Psicologia, garantindo que todos os diagramas, requisitos, regras,dados e critérios de qualidade descrevam o mesmo produto? <br>
