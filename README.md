**Sobre o projeto:**

Este projeto foi desenvolvido como parte da avaliação AV3 da disciplina de Análise Orientada a Objetos. Seu objetivo é transformar um problema real relacionado à gestão de serviços de profissionais de Psicologia em uma modelagem orientada a objetos consistente, verificável e suficientemente detalhada para orientar uma futura implementação.

A proposta consiste na modelagem de uma Plataforma de Gestão de Psicologia, considerando aspectos como gerenciamento de usuários, profissionais, unidades, pacientes, agendamentos e registros de atendimentos.

**Problema:**

Como modelar uma plataforma flexível e segura para profissionais de Psicologia, garantindo que os requisitos, regras de negócio, diagramas, dados e critérios de qualidade representem de forma consistente o mesmo sistema?

**Objetivo**

Desenvolver a modelagem de uma plataforma de gestão voltada para clínicas e profissionais de Psicologia, aplicando os conceitos de Análise Orientada a Objetos e utilizando técnicas de especificação e modelagem de sistemas.

O trabalho busca garantir a coerência entre os requisitos levantados, as regras de negócio, os modelos UML e as demais definições necessárias para uma futura implementação.
